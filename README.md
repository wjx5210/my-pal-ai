# My Pal AI

一个面向《幻兽帕鲁》的命令行 AI 攻略助手。项目将本地结构化帕鲁资料与大语言模型结合，可以识别用户问题中的帕鲁和查询意图，按需筛选上下文，并生成中文攻略或多帕鲁对比建议。

> 当前项目处于 MVP 阶段，主要用于验证“本地知识检索 + 意图路由 + LLM 回答”的 Agent 工作流。

## 功能特性

- 按完整名称或部分名称查询帕鲁
- 从自然语言问题中识别帕鲁名称
- 支持多个搜索结果的交互式选择
- 支持多帕鲁对比与选择建议
- 使用 LLM 识别地点、战斗、工作、掉落、比较等问题意图
- 根据意图裁剪本地资料，减少无关上下文
- 对 LLM 返回的意图执行白名单校验
- 统一管理 DeepSeek 客户端，并处理超时、空响应和调用异常
- 使用 pytest 覆盖核心查询、上下文路由和意图分类流程

## 工作流程

```text
用户输入
  ├─ 直接输入名称 → 本地搜索 → 展示资料 → 生成 AI 攻略
  ├─ 问题中包含一个帕鲁 → 意图识别 → 上下文筛选 → 针对性回答
  ├─ 问题中包含多个帕鲁 → 意图识别 → 多帕鲁上下文 → 对比建议
  └─ 未识别到帕鲁 → 通用 AI 回答
```

当前支持的意图类型：

| 意图 | 含义 | 主要使用的本地资料 |
| --- | --- | --- |
| `location` | 出现地点 | 属性、地点 |
| `combat` | 战斗能力与培养价值 | 战斗定位、推荐阶段、推荐理由 |
| `work` | 基地工作能力 | 工作适应性 |
| `drop` | 掉落材料 | 掉落物 |
| `compare` | 多帕鲁比较 | 属性、战斗、工作、地点、掉落及推荐信息 |
| `other` | 其他问题 | 完整帕鲁资料 |

## 环境要求

- Python 3.10 或更高版本
- 可用的 DeepSeek API Key
- 能够访问 DeepSeek API

## 快速开始

### 1. 创建并激活虚拟环境

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

在项目根目录创建 `.env` 文件：

```dotenv
DEEPSEEK_API_KEY=你的_API_Key
```

`.env` 已加入 `.gitignore`，请勿将真实密钥提交到版本库。

### 4. 启动程序

在项目根目录执行：

```bash
python -m app.main
```

输入 `exit` 可以退出程序。

## 使用示例

```text
请输入帕鲁名称或提问：棉悠悠
```

程序会展示本地资料，并根据资料生成简洁的 AI 攻略。

```text
请输入帕鲁名称或提问：棉悠悠在哪里抓？
```

程序会识别为 `location` 意图，只选取相关地点资料后生成回答。

```text
请输入帕鲁名称或提问：棉悠悠和企丸丸哪个更值得前期培养？
```

程序会识别多个帕鲁并生成对比建议。

## 本地数据格式

每个帕鲁使用一个 JSON 对象表示，主要字段如下：

```json
{
  "name": "帕鲁名称",
  "element": ["属性"],
  "summary": "简介",
  "work_suitability": {},
  "combat": {
    "positioning": "战斗定位",
    "strengths": [],
    "weaknesses": []
  },
  "drops": [],
  "locations": [],
  "recommended_stage": "推荐阶段",
  "recommendation": "推荐理由",
  "tips": "攻略提示"
}
```

目前 `data/pals.json` 包含 5 个帕鲁：棉悠悠、企丸丸、皮皮鸡、冰棘兽和冰帝美露帕。其中部分条目仍以流程测试为主，资料有待继续补充。

## 当前限制

- 本地知识库规模较小，无法覆盖游戏中的全部帕鲁。
- 帕鲁识别目前基于名称字符串匹配，暂不支持别名、错别字和语义实体识别。
- 未识别到本地帕鲁时会使用通用模型回答，准确性取决于模型自身知识。
- 当前仅提供命令行交互，尚未提供 Web 页面或 HTTP API。
- 尚未实现多轮会话记忆、检索排序和答案引用来源。
